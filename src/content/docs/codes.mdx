# California Codes <Badge text="Live explorer" variant="success" />

The explorer reads the section-level legislative snapshot directly. Select a code, then search by section number, citation, statutory text, or hierarchy path.

<Aside type="tip" title="Fastest way to find a section">
  Choose a code first, then enter a section number such as **187** or a phrase such as **public records**. The explorer shows the first 100 matches.
