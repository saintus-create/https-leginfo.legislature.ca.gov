## What this project contains

<CardGrid>
  <Card title="A structured corpus">
    The repository stores section-level records for the California Constitution and the California statutory codes.
  </Card>
  <Card title="Research infrastructure">
    Deterministic retrieval, statutory relationships, temporal records, citations, and AI reasoning are kept as separate layers so the answer can be inspected rather than merely trusted.
  </Card>
</CardGrid>

<Aside type="caution" title="Reference use">
  This project is a structured copy of information published by the California Legislature. Consult the [official source](https://leginfo.legislature.ca.gov/) for authoritative current text.
</Aside>
