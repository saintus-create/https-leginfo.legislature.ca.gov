## What this project contains

<CardGrid>
  <Card title="A structured corpus">
    The repository stores section-level records for the California Constitution and the 29 California statutory codes.
  </Card>
  <Card title="Reproducible tooling">
    The canonical snapshot is JSON Lines, compressed one file per code. A SQLite database and retrieval-ready Markdown corpus can be generated from that source of truth.
  </Card>
</CardGrid>

<Aside type="caution" title="Reference use">
  This project is a structured local copy of information published by the California Legislature. Consult the [official source](https://leginfo.legislature.ca.gov/) for authoritative current text.
</Aside>
